# Дуэт — семейный бюджет на двоих

Веб-приложение (PWA) для учёта денег вдвоём: Миша и Арина ведут записи каждый со своего iPhone, а приложение показывает общие траты или траты одного из вас. Траты можно добавлять скриншотом из банковского приложения: Claude прочитает операции и разложит их по категориям.

Всё бесплатно, кроме распознавания скриншотов: вы платите Anthropic за каждый запрос, обычно это копейки.

## Что внутри

- **Обзор**: счета с балансами, денежный поток за месяц, график баланса, круговая диаграмма расходов (по категориям или по людям), последние записи, крупнейшие траты, бюджеты, регулярные платежи.
- **Планы**: регулярные платежи с повтором (раз в неделю, месяц или год, кнопка «Оплачено — записать») и бюджеты на месяц.
- **Статистика**: плитки и отчёт «Доходы и расходы» со сравнением с прошлым периодом, подкатегории, сводка движения денег. Период выбирается внизу: 7/30 дней, 12 недель, 6 месяцев, год; календарный месяц или неделя со стрелками; свои даты.
- **Скриншот → записи**: загружаете снимки экрана из банка и проверяете найденные операции. Категорию можно поменять, похожие на уже добавленные записи сняты с галочки. Потом жмёте «Добавить».
- **Чья запись**: каждая запись помечена как «Миша» или «Арина». Переключатель «Общее / Миша / Арина» есть на Обзоре, в Статистике, Отчётах и Записях. В Отчётах есть блок «По людям»: кто сколько заработал и потратил, со сравнением с прошлым периодом.
- **Фильтр** (кнопка «Фильтр» на Обзоре, в Статистике, Отчётах и Записях) отбирает записи по человеку, счетам, категориям (целой группе или отдельным подкатегориям) и меткам. Действует сразу на всю аналитику: суммы, диаграммы, отчёты, «По людям», списки. Что сейчас отфильтровано, видно по плашкам под заголовком; крестик убирает одно условие, «Сбросить» убирает все.
- **Шаблоны** для частых операций (кофе, бензин, проезд):
  - на Обзоре одно нажатие на шаблон сразу добавляет запись, а в уведомлении есть кнопка «Отменить»;
  - в форме записи кнопка «Шаблоны» или «Из шаблона» заполняет поля, и можно поправить сумму;
  - «Сохранить как шаблон» превращает текущую запись в шаблон;
  - управлять шаблонами можно в разделе «Ещё → Шаблоны»;
  - шаблоны общие для обоих телефонов, а запись из шаблона ставится на того, кто нажал.

## Счета

Счета уже созданы. Остаётся ввести текущие балансы: **Ещё → Счета**, нажать счёт, заполнить «Баланс сейчас».

| Миша | Арина | Общие |
|---|---|---|
| Наличные, ПСБ, Сбер, Т-Банк, Озон | Наличные, Сбер, Т-Банк, Озон | Подушка ₽, Подушка $, Подушка € |

- На Обзоре счета разбиты по людям, у каждого раздела указана сумма. Три счёта «Подушки» показаны одной плиткой: в каждой валюте отдельно и в сумме в рублях.
- Если выбрать в записи карту Арины, запись сама ставится на Арину, и наоборот.
- Чтобы купить валюту, сделайте «Перевод» с карты на «Подушка $» и укажите, сколько долларов пришло. Приложение покажет курс обмена.
- Аналитика и общие балансы считаются в рублях. Доллары и евро пересчитываются по курсу ЦБ, он обновляется сам, а в Настройках его можно задать вручную. Траты в валюте пересчитываются по текущему курсу, а не по курсу на день покупки.
- Новый счёт добавляется кнопкой «Новый счёт»: там выбираются владелец, валюта и «Объединить в».

## Как всё устроено

```
iPhone Миши ─┐                        ┌─ GitHub Pages (само приложение, бесплатно)
             ├─ приложение «Дуэт» ────┤
iPhone Арины ┘                        └─ приватный репозиторий: ledger.json (ваши данные)
```

Данные сначала сохраняются на телефоне, поэтому приложение работает и без интернета. Раз в минуту, при каждом изменении и при открытии приложения телефон забирает `ledger.json` из приватного репозитория, сливает его со своими записями и записывает обратно. Если оба телефона пишут одновременно, приложение перечитывает файл и повторяет запись, так что изменения не теряются. Удалённые записи тоже доходят до второго телефона.

## Настройка (один раз, около 15 минут)

### 1. Репозиторий для данных (приватный)

1. На GitHub: **New repository**, имя, например, `duet-data`, видимость **Private**, галочка **Add a README file**.
2. Создайте токен: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: **Only select repositories** → `duet-data`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Срок действия выберите сами: когда токен истечёт, приложение напишет об ошибке синхронизации.
3. Скопируйте токен: он понадобится на обоих телефонах.

### 2. Репозиторий для приложения

GitHub Pages бесплатно работает с **публичным** репозиторием. В коде приложения нет ни данных, ни ключей, поэтому его можно открыть.

1. Создайте репозиторий, например `duet`, видимость **Public**.
2. Загрузите в него содержимое этой папки:
   ```bash
   git init
   git add .
   git commit -m "Дуэт"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/duet.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages → Source: GitHub Actions**.
4. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ_ЛОГИН.github.io/duet/`. После каждого `git push` оно пересобирается само.

### 3. Ключ для распознавания скриншотов

1. Зайдите на [platform.claude.com](https://platform.claude.com), раздел **API keys → Create key**, и пополните баланс на небольшую сумму.
2. Ключ вводится в приложении: **Ещё → Настройки → Ключ Anthropic**. Он хранится только на телефоне и в GitHub не попадает.
3. По умолчанию стоит модель Opus 5.5, она точнее всех. Если хочется дешевле, выберите Sonnet 5.5 или Haiku 5.5.

### 4. На каждом iPhone

1. Откройте адрес приложения в **Safari** → «Поделиться» → **На экран «Домой»**.
2. Запустите иконку «Дуэт» и выберите, кто вы: Миша или Арина.
3. **Ещё → Синхронизация**: логин GitHub, `duet-data`, файл `ledger.json`, токен → **Проверить и подключить**.
4. Чтобы распознавать скриншоты, введите ключ Anthropic в **Настройках**.

## Разработка

```bash
npm install
npm run dev
npm run build
```

Стек: Vite + Preact, без сервера. Код по папкам:

- `src/data/`: категории, хранилище, синхронизация с GitHub, расчёты периодов.
- `src/ai/scan.js`: распознавание скриншотов через Claude API (официальный SDK `@anthropic-ai/sdk`, ответ строго по JSON-схеме).
- `src/ui/`: экраны.

## Безопасность

- Токен GitHub и ключ Anthropic хранятся только в памяти браузера на телефоне.
- Токен GitHub даёт доступ только к одному репозиторию с данными.
- Скриншоты уходят в Anthropic только в момент распознавания и нигде не сохраняются.
- Ключ Anthropic, указанный в браузере, может прочитать любой, кто держит телефон в руках. Поставьте на него лимит расходов в консоли Anthropic.
